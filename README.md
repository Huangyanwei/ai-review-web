# 评审预演 · AI 模拟评审会

根据《AI 模拟评审会工具 PRD v1.0》制作的独立 Web 工具。无需安装浏览器扩展或依赖，可部署到 GitHub Pages 等静态网站服务。

## 本地运行

可直接用浏览器打开 `index.html`。如果浏览器限制本地文件功能，也可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 当前实现

- 粘贴文档内容，或导入 Markdown / TXT 文件。
- 六角色预设、快审/标准/深度档位、问题数量估算。
- 原文引用、回答/待补充/跳过、回答不足时追问。
- 评审进度在本地保存 24 小时、完成报告、质量反馈、Markdown 复制、历史记录和本地数据删除。
- 文档与评审记录只保存在当前浏览器的本地存储中，不会上传。

## 模型接入说明

当前是本地交互原型：问题由预设规则从文档段落生成。AI 问题生成、账号同步和会员额度需要部署服务端接口后再接入；不要把模型密钥放在网页前端代码中。
